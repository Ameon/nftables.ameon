# Changelog

## [0.0.1] - 2026-11-17

### Added

- Syntax highlighting for nftables configuration files.
- Highlighting for tables, chains, sets, maps and counters.
- Highlighting for object declarations and references.
- IPv4 and IPv6 address highlighting.
- Keywords, protocols, operators and actions highlighting.
- Comment and string highlighting.
- Automatic bracket closing and matching.
- Automatic indentation.
- Support for `.nft` files.
